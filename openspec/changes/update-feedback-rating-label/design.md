## Context

The Student Feedback form's Rating section label on `public/feedback.html` currently reads "Rating (1-5)" (line ~812). The label is a plain `<label class="student-form-label feedback-label">` with no `for`/`id` binding to a specific control (the radios use `name="rating"` with `rating1..5` ids). The request is a wording-only change to "Ratings".

## Goals / Non-Goals

**Goals:**
- Change the label text in the Student Feedback form from "Rating (1-5)" to "Ratings".
- Update the corresponding wording in the `student-feedback-ui-layout` main spec.

**Non-Goals:**
- No changes to rating buttons, helper text, styling, spacing, layout grid, functionality, the Priority section, or any other page element.
- No change to the Returns page modal, which has its own "Rating (1-5)" label (`public/returns.html:910`) — out of scope.

## Decisions

**D1: Edit the label text in place.**
Replace the text content of the Rating label element in `public/feedback.html` only. No markup, class, or structural changes.
- Rationale: The label is static HTML (not generated by `feedback.js`), so a one-line text edit fully implements the change.
- Alternative considered: the feedback.js modal/details strings ("Rating:") — not requested; left untouched.

**D2: Mirror the wording in the spec delta.**
The delta spec updates the "Two-column submit form layout" and "Rating and priority controls" requirements so the label is written as "Ratings" consistently with the UI.
- Rationale: Keeps the archived main spec in sync with the rendered page.

## Risks / Trade-offs

- [Wording drift between page and specs] → Both are updated in the same change; no other references to "Rating (1-5)" exist in `student-feedback-ui-layout.spec.md` beyond these requirements (the Returns modal is a separate page/spec scope).
- [Accidental broader edits] → Task list constrains edits to the single label element and the spec delta; no JS or CSS touched.

## Migration Plan

1. Edit the label text in `public/feedback.html`.
2. Update the spec delta to use "Ratings".
3. Visual check in browser to confirm the label changed and nothing else moved.
