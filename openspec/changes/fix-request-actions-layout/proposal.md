## Why

The Pending Registrations (Request Management) Actions column renders its four buttons (View, ORF, Approve, Archive) as a single inline-flowing `<td>` with uneven `ml-2` margins, so buttons wrap unpredictably, misalign across rows, and the column is neither properly sized nor vertically centered. This makes the actions area look inconsistent with the rest of the smart-serve admin UI.

## What Changes

- Render the Pending Registrations Actions column as a consistent 2-row button grid: `[ View ] [ ORF ]` on the first row and `[ Approve ] [ Archive ]` on the second.
- Introduce a shared `.action-buttons` grid container (2 equal-width columns, uniform 6px gap) applied to every pending registration row.
- Update the button classes supplied by `appendRegistrationRow` in `public/js/admin.js` so each grid button fills its cell (`w-full`, centered, no wrapping) and leading `ml-2` margins are dropped inside the grid.
- Change the Archive button to the existing blue/white action style (consistent with View), per the accepted button styling; no new colors introduced.
- Size and vertically center the Pending Registrations Actions column without changing the table structure or column count (7 columns retained), the empty-state `colSpan`, or any other table.
- Confirmed scope boundaries: no Reject/Remove/Delete button anywhere in the actions column (Reject was already removed previously; only View/ORF/Approve/Archive remain for pending requests).
- No change to Approved/Rejected registrations tables, Inventory Management Actions (`[ Edit ] [ Archive ]`), other modules, page/sidebar/header/filters, colors, typography, or button functionality/event handlers.

## Capabilities

### New Capabilities
- `registration-actions-layout`: Layout and presentation of the Pending Registrations (Request Management) administrator action buttons — the 2x2 grid, Actions column sizing and vertical centering, button sizing/alignment, and the explicit View/ORF/Approve/Archive button set.

## Impact

- `public/js/admin.js` — `appendRegistrationRow()` (~line 2414): wrap the pending-row actions in an `.action-buttons` grid container, adjust button utility classes (remove `ml-2`, add `w-full justify-center whitespace-nowrap`) for grid layout, restyle Archive button to blue/white. Approved/Rejected paths are intentionally left with the current inline flow.
- `public/css/admin.css` — add scoped rules for `#registrationsTable`: `.action-buttons` grid (repeat(2, minmax(0, 1fr)), gap 6px, width 100%), Actions column width, and vertical centering of the actions cell.
- `public/admin.html` — no markup change required (rows are generated by JS; 7-column header and `colSpan="7"` empty state stay intact).
- No API/backend, no new dependencies, no behavioral change to existing handlers (`viewUser`, `event selection` for ORF link, `updateRegistrationStatus`, `archiveRegistration`).
